# NOVELTY_ASSESSMENT (final)

## Claim (narrowest defensible)
> We treat individual ages, grouped/life-table data, and maximum-only reports
> as three distinct observation types generated by a common latent mortality
> process; we separate assemblage formation (attritional vs catastrophic
> standing crop), age-dependent observation q(a), and age-estimation error;
> and we validate recoverability by degrading known extant demographic
> schedules into fossil-like samples, producing an explicit recoverability map.

## Novel elements (with precedent check)
| Element | Novel? | Closest precedent / delimiter |
|---|---|---|
| Order-statistic likelihood for fossil maxima, p(M)=n·g·G^(n−1) under *observed* g | yes, for fossil demography | sampling-effort regressions on maxima in ornithology/zoo records (Moorad 2012; Møller line) — different mechanism, regression not likelihood |
| Joint likelihood over {individual ages, grouped counts, max-only} without double counting | yes | no prior implementation found in paleodemography |
| Explicit (F,q) non-identifiability demonstration + q-scenario reporting | strengthened novelty | S&O 2011 illustrated one bias case; we show the structural argument and its quantitative cost |
| Assemblage mechanism as explicit model scenario incl. r | partially | Griebeler 2021 established the SAD requirement; we embed mechanism+r in likelihood and report estimate ranges |
| Recoverability map from degraded extant schedules | yes | S&O used power analysis for rate-ratio tests only |
| Standardized E[M_n*] reporting metric | new proposal | related to ornithological adjusted-max-lifespan regressions but model-based |

## Explicit non-claims
Not first to: fit survival curves to dinosaurs; use Weibull/Gompertz/Siler in
paleodemography; discuss taphonomic or collection bias; build life tables
from fossil assemblages; note that max reported lifespan grows with sampling.
