# PALEOBIOLOGY_SUBMISSION_REQUIREMENTS

Verified against Cambridge Core author instructions and the Paleobiology
Accepted Manuscript Styleguide (checked 2026-09-29; styleguide last updated
2015-04-07 — retained as the governing style document).

## Article type / scope
- Original research article. Paleobiology publishes quantitative work on
  paleobiological processes; this methods/recoverability paper fits.
- No explicit word limit found for articles; keep concise. Memoirs series
  exists for oversized works — not needed.

## Structure (required order)
title page → abstract page → text → Literature Cited → appendix →
figure captions. Supplemental data reposited online (Dryad/Zenodo).

## Formatting (submission for review)
- Double-space EVERYTHING, 12-pt Times New Roman (incl. Literature Cited,
  captions, appendices).
- Continuous line numbers on the review version; all pages numbered
  starting at title page.
- 1-inch margins; US Letter; no right/full justification; no hyphenation
  at right margin.
- No footnotes (except in tables); no underlining.

## Title page
- Boldface title; capitalize first word + proper names only; no period.
- Author full names below; running heads ≤50 chars each:
  RRH = running title (caps); LRH = author name(s) (caps, "ET AL." if >2).

## Abstract page
- ≤300 words; own page; italicized "Abstract" + period + em-dash
  ("Abstract.—"), flush left.
- Author names + full addresses + e-mail after abstract, italicized,
  hanging indent; no abbreviated Dept./Ave.

## Headings
- Primary: centered, bold, title case.
- Secondary: flush left, title case; text next line indented.
- Tertiary: indented, italicized, followed by period + em-dash, text same
  line ("Heading.—Text").

## Citations — AUTHOR-DATE (not Vancouver)
- (Author year); two authors "A and B"; ≥3 "A et al."; no comma before
  year; chronological ordering; semicolons between authors; commas for
  same author; pages after colon.
- Figure in text: spelled-out "Figure 1"; parenthetical "(Fig. 1)";
  "Table"/"Appendix" spelled out; equations "equation (2)" / "(eq. 2)".
- Equations numbered (n) at right margin; "Equation (6) shows...".

## Literature Cited
- Alphabetical by surname; hanging indent (no tabs); journal names
  unabbreviated; article titles title case, subtitle lowercase after colon.
- Author form: "Woodward, H. N., E. A. Freedman Fowler, J. O. Farlow,
  and J. R. Horner. 2015."
- Same-author repeats → three em-dashes; year+a/b for same-author same-year.
- DOIs not required by style but permitted/encouraged.

## Tables
- Editable Word tables (create-table, not tabs/images); caption above
  table, same page; no vertical borders.

## Figures (Cambridge art guidelines)
- Do NOT embed in the submission text file (upload individually);
  parts labelled with capital letters, no parens/periods.
- Sans serif font (Arial/Helvetica); final lettering ≥1.5 mm; fonts
  embedded in TIF/EPS; max 72 mm (1-col), 148 mm (2-col), 148×215 mm page.
- Must specify intended column width.
- Color in print = $250/figure mandatory; grayscale print + online color
  free — all figures must be legible in grayscale OR declare color print.
- WCAG 2.1 AA: alt-text descriptions required (Accessibility Descriptions
  form); don't rely on color alone.

## Declarations / submission system
- Cover letter mandatory; all figures + tables uploaded individually.
- ORCID required for corresponding author (ScholarOne).
- Licence-to-publish or OA form at acceptance; Gold OA APC available.
- AI use must be declared: generative AI used for text/analysis →
  declare in acknowledgments/methods (name+version of tool, dates, use).
- No simultaneous submission; preprints allowed.
- Data/code/supplement: Paleobiology covers Dryad + Zenodo costs; files
  not CC0-able go to Zenodo as "Supplemental Information" (CC BY).
- Supplementary files titled "Supplementary Figure 1" etc., cited in text.

## Consequences for this package
1. Convert numbered Vancouver citations → author-date + alphabetical
   Literature Cited.
2. Two manuscript files: inline review copy (figures embedded, reader
   convenience) and submission text file (title page, abstract page,
   double-spaced, line numbers, captions at end, no embedded figures).
3. Add title page + running heads; Abstract.— format; heading levels.
4. Number equations; check text refs "equation (n)".
5. Figure files need column-width spec + grayscale check + alt-text.
6. Declarations: Data Availability (Dryad pending — do not claim done),
   funding, competing interests, author contributions, AI-use statement.
